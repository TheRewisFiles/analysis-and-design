Project Overview

The projects in this course focused on using data structures and algorithms to solve programming problems. The main problem I worked on was creating an advising assistance program for ABCU. The program needed to load course information from a file, store the course data in a data structure, print a list of courses in alphanumeric order, and allow a user to search for a specific course to view its title and prerequisites.

What Was the Problem I Was Solving?

The problem was to help academic advisors access course information quickly and clearly. Advisors needed a way to view all computer science courses in order and look up individual courses with their prerequisites. To solve this, I had to think about how course data should be stored, searched, and printed efficiently.

How Did I Approach the Problem?

I approached the problem by comparing different data structures, including vectors, hash tables, and binary search trees. Each structure had advantages and disadvantages. Vectors are simple and easy to use, but searching can take longer. Hash tables are very fast for searching, but they do not naturally keep data in sorted order. Binary search trees are useful because they allow searching and can print data in sorted order using an in-order traversal.

Understanding data structures is important because the structure chosen affects how efficient and organized a program is. Choosing the wrong structure can make a program slower or harder to maintain.

How Did I Overcome Roadblocks?

One roadblock I encountered was understanding how different data structures handled searching, sorting, and storing data. I worked through this by breaking the problem into smaller parts and comparing the Big O runtime of each structure. I also tested code step by step instead of trying to complete everything at once. When errors came up, I focused on reading the error messages carefully and fixing one issue at a time.

How Has This Expanded My Approach to Software Design?

This project helped me think more about planning before writing code. Instead of only focusing on getting the program to work, I had to think about which data structure made the most sense for the problem. It also helped me understand that software design is about making choices that affect performance, readability, and future changes.

How Has This Changed the Way I Write Programs?

My work in this course helped me write programs that are more maintainable, readable, and adaptable. I used functions to separate different tasks, such as loading data, printing courses, and searching for a course. I also used clearer variable names and comments to make the code easier to understand. This made the program easier to test, debug, and update.
